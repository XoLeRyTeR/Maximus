# AgroGrant

Структура проекта создана. Файлы исходного кода и конфигурации пока пустые.

- `frontend/` — мини-приложение MAX на React и TypeScript.
- `backend/` — API, MAX-боты, подбор и уведомления на TypeScript.
- `worker/` — сбор документов и обработка через GigaChat на Python.
- `docs/` — архитектура, сценарии, источники и факты для презентации.
- `backend/migrations/` — схема PostgreSQL.
