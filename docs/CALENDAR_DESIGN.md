# Календарь грантов и субсидий — дизайн MVP

Интерактивный макет: [`frontend/calendar-preview.html`](../frontend/calendar-preview.html). Он открывается как обычный HTML-файл и содержит только примерные данные, не реальные сроки отбора.

## Сценарий

Пользователь открывает мини-приложение MAX и видит ближайший подтверждённый дедлайн, календарь месяца и карточки выбранной даты. Оранжевая точка означает дедлайн подачи. Отдельная вкладка «Срок уточняется» показывает программы без подтверждённой даты: они не попадают на календарную сетку и не обозначаются как открытый приём.

В карточке реальной меры должны быть название, тип, регион, краткое описание, дата и время окончания при наличии, ссылка на официальный источник и состояние заявки пользователя. По нажатию на карточку открывается экран подробностей с условиями и документами. Действие «Хочу податься» сохраняет меру в «Мои заявки»; само по себе оно не отправляет заявку в ведомство.

## Данные и правила

- Дедлайны брать из `support_measures.application_deadline`. `NULL` отправлять в «Срок уточняется».
- В календаре в первую очередь показывать `kind='selection'`, то есть конкретные отборы. Записи `kind='measure'` без отбора держать в разделе программ, чтобы не дублировать один и тот же конкурс.
- Региональный фильтр: Ивановская область и федеральные меры. Подбор по направлениям хозяйства добавлять после подтверждения профиля пользователя.
- Источник и дату последней проверки показывать в деталях. У федерального вторичного каталога условия сверять с официальным документом до обозначения подтверждённого приёма.
- Прошедшие сроки сохранять доступными в истории, но не считать актуальными.
- Если несколько мер заканчиваются в один день, показывать все карточки в списке этой даты.

## Следующий этап реализации

После согласования макета перенести компоненты в `frontend/src/App.tsx`, подключить API календаря и авторизацию MAX. В API вернуть список мер с `id`, `title`, `kind`, `region`, `application_start`, `application_deadline`, `source_url`, `last_seen_at` и пользовательским статусом заявки.
