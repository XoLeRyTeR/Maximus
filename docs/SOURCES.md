# Источники мер поддержки

| Источник | URL | Что извлекаем |
| --- | --- | --- |
| Департамент сельского хозяйства Ивановской области | https://apk.ivanovoobl.ru/deyatelnost/gosudarstvennaya-podderzhka-/ | Таблица видов поддержки и нормативные акты |
| Департамент, отбор получателей | https://apk.ivanovoobl.ru/deyatelnost/otbor-poluchateley-subsidiy/obyavleniya-o-provedenii-otbora-poluchateley-subsidiy/ | Объявления, дата публикации, PDF и сроки подачи из текста PDF |
| Своё Фермерство | https://svoefermerstvo.ru/mery-podderzhki | Федеральный каталог для предварительного поиска |

Региональные объявления и перечень мер — официальные источники. Федеральный каталог является вторичным: данные из него нельзя представлять как действующий отбор без сверки с официальным документом. На 28 сентября 2026 года каталог показывает 161 страницу по 4 карточки; worker обходит их через `?page=N`.

`promote.budget.gov.ru` пока не используется в worker: автоматический запрос к его главной странице получил HTTP 403. Для подключения необходим проверенный публичный endpoint или официальный способ выгрузки.
