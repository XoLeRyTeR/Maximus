# Промпты backend

Для каждой задачи модели создаём отдельный модуль в этой папке. Модуль хранит системные правила, few-shot примеры и функцию сборки сообщений. Клиент GigaChat и проверка ответа остаются в `src/integrations`.

`activity_classification.ts` классифицирует направления хозяйства. Он также задаёт JSON-схему ответа GigaChat, чтобы модель возвращала только допустимые метки. Закрытый список меток задан в `src/activity_labels.ts`; при изменении меток обновите примеры и проверку в `scripts/smoke-onboarding.mjs`.
